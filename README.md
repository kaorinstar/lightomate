# Lightomate

Lightomate（ライトメイト）は、Web 上の操作を自動化する Chrome 拡張機能（Manifest V3）です。
名称は Light、Automate、Mate を組み合わせたものです。

ログイン済みの Chrome の画面をそのまま使い、ページの要素を直接操作するため、Power Automate for
desktop より軽く動作します。Chrome ウェブストアでは公開せず、デベロッパーモードで読み込んで
個人で使います。

操作の記録と実行、実行時の値の入力、条件分岐と繰り返し、複数のフローの一括実行（まとめフロー）、
決まった日時の自動の実行（定期実行）、ページの PDF 保存ができます。予定している機能と進捗は https://github.com/kaorinstar/lightomate/issues で
管理しています。

## 利用上の注意

- 購入や申し込みの確定は、必ず人が行ってください。Lightomate は、確定ボタンの手前で実行を止める
  仕組みを備えています。記録中に確定ボタンを押すと、その操作は一時停止として記録されます。実行中は、
  ボタンを押す直前にその文言を確かめ、確定ボタンであれば押さずに止まります。
- この仕組みは、ボタンの文言（「注文を確定する」「Buy now」など）と、ボタンの `id` や `name` などの属性
  （`placeOrder` など）で判定します。属性は Chrome の翻訳で変わらないため、翻訳を有効にしていても判定
  できます。ただし、すべてのサイトで検出できるとは限りません。画像だけで説明のないボタンや、独自の文言のボタンは検出できない
  場合があります。フローを実行する前に、確定ボタンの手前に一時停止の手順があることを確認してください。
- 文言で判定できないボタンや画面は、フローの管理画面の「必ず止まる場所（サイトごと）」で、サイトごとに
  指定できます。止める要素（CSS セレクター、例：`#placeOrder`）と止める画面（URL のパス、例：
  `/checkout/*`）を指定すると、そのサイトのすべてのフローが、その手前で止まります。
- ［設定］タブの「確定ボタンの自動検出」で［確定ボタンの手前で止めない］を選ぶと、この仕組みを無効にできます。
  無効にすると、フローが確定ボタンを押し、購入や申し込みが確定する可能性があります。誤って確定した場合の損害は、
  利用者の責任になります。選ぶ前に確認を表示し、選んでいる間はサイドパネルの見出しの横に印を表示します。定期実行は、
  続けて［定期実行でも止めない］を選ばない限り、確定ボタンの手前で止まります。選ぶと、人がその場にいない間に
  確定する可能性があります。「必ず止まる場所」で指定した場所では、どちらの設定でも止まります。
- 記録中に確定ボタンを押すと、記録とは別に、その場で実際に確定します。記録するときは、確定ボタンを
  押さずに記録を停止してください。
- 実行中のフローは、Alt+Shift+Q でいつでも停止できます。サイドパネルを開いていなくても、実行中と
  一時停止中のすべてのフローを停止します。ほかの拡張機能と組み合わせが重なって効かない場合は、
  chrome://extensions/shortcuts で Lightomate の「実行中のフローをすべて停止する」のキーを変更してください。
- 複数のサイトのフローは、「まとめフロー」としてまとめて実行できます。フローの管理画面の［保存したフロー］で
  フローを選び、［まとめフローとして保存］を押して登録し、サイドパネルの［まとめフロー］のタブか、管理画面の
  ［まとめフロー］のタブから実行します。
  別のサイトのフローは背景のタブで並行して実行し、同じサイトのフローは登録した順に 1 件ずつ実行します。
  確定ボタンの手前で止まったフローは、確定を済ませてからサイドパネルの［確認済み・次へ］を押してください。
  押すまで、同じサイトの次のフローは始まりません。
- 実行中にログインの有効期限が切れるなどして、ログインや認証の画面が表示された場合は、一時停止します。
  ログインなどを済ませて元の画面に戻り、サイドパネルの［再開］を押すと、続きから実行します。
- フローの管理画面の「定期実行」で、毎日・毎週・毎月の決まった時刻にフローを自動で実行できます。
  Chrome を起動している間だけ実行し、開始・完了・一時停止を Windows の通知で知らせます。定期実行でも、
  確定ボタンの手前とログインの画面では一時停止します。同じサイトのフローを実行中の場合は、終わるまで
  待ってから実行します。

## 読み込み方

Chrome ウェブストア以外で入手した拡張機能のファイル（`.crx`）は、Windows と macOS の Chrome では
インストールできません。そのため、フォルダーを Chrome に読み込んで使います。Chrome 116 以降が必要です。

### Windows（更新用のファイルを使う方法）

1. https://github.com/kaorinstar/lightomate/releases/latest を開き、`lightomate-update.bat` を
   ダウンロードします。
2. ダウンロードしたファイルを実行します。「ブランチ名」と尋ねられたら、何も入力せずに Enter を押します。
   最新の版が、「ダウンロード」フォルダーの中の `Lightomate` フォルダー
   （例：`C:\Users\<ユーザー名>\Downloads\Lightomate`）に展開されます。
   「Windows によって PC が保護されました」と表示された場合は、［詳細情報］→［実行］を押します。
3. Chrome で chrome://extensions を開き、右上の［デベロッパー モード］を有効にします。
4. ［パッケージ化されていない拡張機能を読み込む］を押し、手順 2 のフォルダーを選びます。
5. ツールバーの Lightomate のアイコンを押すと、画面の右側にサイドパネルが開きます。

更新するときは、`lightomate-update.bat` をもう一度実行し、chrome://extensions の Lightomate の
［再読み込み］ボタンを押します。読み込み直す必要はありません。

「ダウンロード」フォルダーを整理するときは、`Lightomate` フォルダーを削除しないでください。削除すると
拡張機能が動作しなくなります。削除した場合は、`lightomate-update.bat` を実行すると元に戻ります。

作り直す前の v0.1.0 の `lightomate-update.bat` は、`%USERPROFILE%\Lightomate` に展開していました。そのフォルダーを
読み込んでいた場合は、新しい版の `lightomate-update.bat` を実行した後に、手順 4 の操作で `Downloads` の
中の `Lightomate` フォルダーを選び直します。［削除］は押しません。保存したフローは残ります。

### ZIP を使う方法

1. https://github.com/kaorinstar/lightomate/releases/latest を開き、`lightomate-vX.Y.Z.zip` を
   ダウンロードして展開します。展開したフォルダーに `manifest.json` が入っています。
2. 上の手順 3〜5 と同じ操作で、展開したフォルダーを読み込みます。

更新するときは、新しい版の ZIP の中身を、前と同じフォルダーに上書きします。その後、chrome://extensions の
Lightomate の［再読み込み］ボタンを押します。

### 開発中の版を使う方法

リリース前の変更（プルリクエストの版）を試す場合は、`lightomate-update.bat` を実行し、「ブランチ名」に
ブランチの名前（例：`feat/54-stop-rules`）を入力して Enter を押します。そのブランチの `extension` フォルダーの
中身が、いつもの `Lightomate` フォルダーに展開されます。その後、chrome://extensions の Lightomate の
［再読み込み］ボタンを押します。

確認が終わったら、`lightomate-update.bat` をもう一度実行し、何も入力せずに Enter を押して、最新の
リリースに戻します。

v0.1.0 のリリースに添付した `lightomate-update.bat` は、ブランチ名を尋ねません。尋ねられない
場合は、https://github.com/kaorinstar/lightomate/blob/main/tools/lightomate-update.bat を開き、
［Download raw file］（下向き矢印のボタン）で新しいファイルをダウンロードします。

このリポジトリを ZIP でダウンロードして展開するか、複製（clone）して使うこともできます。読み込むのは、
リポジトリのフォルダー全体ではなく、その中の `extension` フォルダーです。

### 保存したフローについて

作成したフローは Chrome の中に保存されます。フォルダーの中身を入れ替えても、フォルダーの場所を
変えても失われません。拡張機能の ID を固定しているためです。ただし、chrome://extensions で
拡張機能を［削除］すると、保存したフローも削除されます。更新は［削除］ではなく［再読み込み］で
行います。

Chrome の再インストールや PC の買い替えに備えるには、フローの管理画面の［設定］タブの「バックアップ」で
［すべて書き出し］を押します。保存したフロー、まとめフロー、必ず止まる場所を 1 つのファイルに書き出します。
元に戻すときは、同じ場所の［バックアップから復元］でそのファイルを選びます。復元は追加だけを行い、
今あるデータは消しません。ファイルの形式は `docs/backup-format.md` にあります。

## フローの作り方の例

購入履歴から、指定した月の注文の領収書を 1 件ずつ PDF として保存するフローの作り方を、
[`docs/receipt-flow.md`](docs/receipt-flow.md) に記載しています。対象月の入力、一覧の繰り返しとページ送り、
月による絞り込み、PDF の保存を組み合わせた例です。利用するサイトの利用規約を確認してから使ってください。

期間や検索語など、実行のたびに変える値がある場合は、記録中に手順の一覧の選択か入力の行で
［実行するたびに変える値にする］を押します。月の欄では「前月」か「今月」を、日の欄では「1 日」「末日」「今日」を
選ぶだけです。実行するときに、その値を入力する欄が表示されます。
