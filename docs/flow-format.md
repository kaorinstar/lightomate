# フロー定義の形式（版 2）

Lightomate が記録した操作は、この形式の JSON になります。検証の処理は
`extension/shared/flow.js` にあり、この文書と処理の内容が一致している必要があります。形式を変える場合は、
両方を同時に変更し、`schemaVersion` を 1 増やします。

記録できる操作は、ページの移動、クリック、文字の入力、選択肢の選択の 4 種類です。パラメータ（実行の
たびに変わる値）を定義できます。条件分岐と繰り返しは、後の版で追加します。

| 版 | 内容 |
|---|---|
| 1 | 初版です。 |
| 2 | 一時停止の手順（`pause`）を加えました。版 1 のフローは、変換せずにそのまま版 2 として読み込めます。版 1 のフローに `pause` は書けません。 |

## 全体

```json
{
  "schemaVersion": 2,
  "name": "記録 2026/9/24 14:04:24",
  "origin": "https://www.example.com",
  "steps": [
    { "type": "navigate", "cause": "user", "url": "https://www.example.com/login" },
    { "type": "input", "target": { "...": "..." }, "value": "taro@example.com" },
    { "type": "input", "target": { "...": "..." }, "secret": true },
    { "type": "click", "target": { "...": "..." } },
    { "type": "navigate", "cause": "page", "url": "https://www.example.com/orders" }
  ]
}
```

| 項目 | 内容 |
|---|---|
| `schemaVersion` | 形式の版番号。現在は `2` です。`1` のフローも読み込めます。 |
| `name` | フロー名。記録した日時が初期値です。同じ `origin` に同じ名前のフローがある状態で保存すると、既存のフローを上書きせず、名前に番号を付けて保存します（例：`領収書 (2)`）。 |
| `origin` | 記録を始めたページのオリジン（`https://` または `http://` と、ホスト名とポート番号）。実行時は、このオリジンのページでだけ手順を実行します。 |
| `params` | パラメータの定義（下記の「パラメータ」）。省略できます。 |
| `steps` | 手順の一覧。記録した順に並びます。上限は 1,000 件です。 |

## 手順の種類

### `navigate`：ページの移動

| 項目 | 内容 |
|---|---|
| `url` | 移動先の URL。`https://` または `http://` で始まるものだけです。 |
| `cause` | `user`：利用者の操作による移動（URL の入力、再読み込み、戻る・進む）。`page`：ページの操作による移動（リンク、フォームの送信、転送）。 |

最初の手順は、記録を始めたページの `navigate`（`cause` は `user`）です。実行時に同じページから始める
ためです。

`cause` が `page` の移動は、直前の手順（クリックなど）の結果として起きたものです。実行時は、この手順で
改めて移動するのではなく、移動が終わるのを待つ手順として扱う想定です。

同じページの中で URL だけが変わる移動（`history.pushState` など）は記録しません。

### `click`：クリック

| 項目 | 内容 |
|---|---|
| `target` | クリックした要素（下記の「要素の指定」）。 |

リンクやボタンの内側の文字や画像をクリックした場合は、リンクやボタンそのものを記録します。
文字の入力欄と選択肢へのクリックは、入力の準備にすぎないため記録しません。

### `input`：文字の入力

| 項目 | 内容 |
|---|---|
| `target` | 入力した欄。 |
| `value` | 入力した値。入力を終えて欄から離れた時点の値を 1 回だけ記録します。 |
| `secret` | `true` の場合、値を記録していないことを示します。このとき `value` はありません。 |

次の欄の値は記録せず、`secret: true` とします。保存した JSON から漏れることを防ぐためです。

- パスワードの欄（`type="password"`）
- `autocomplete` 属性が `cc-` で始まる欄（クレジットカード番号、有効期限、セキュリティコードなど）
- `autocomplete` 属性が `one-time-code` の欄（確認コード）

対象の入力欄の種類は、`text`、`email`、`search`、`tel`、`url`、`number`、`password`、`date`、`month`、
`week`、`time`、`datetime-local` と `textarea` です。チェックボックスとラジオボタンはクリックとして記録
します。ファイルの選択欄と、`contenteditable` の要素（文書の編集画面など）は記録しません。

### `select`：選択肢の選択

| 項目 | 内容 |
|---|---|
| `target` | 選択肢の要素（`select`）。 |
| `values` | 選んだ選択肢の `value` の一覧。 |
| `labels` | 選んだ選択肢の表示文字列の一覧。 |

複数選択の場合も記録できるよう、どちらも配列です。

### `pause`：一時停止

| 項目 | 内容 |
|---|---|
| `note` | 止まる理由の説明。省略できます。 |

実行はこの手順で終了し、以降の操作は人が行います。止まった理由はサイドパネルに表示します。続きを
実行する機能（［再開］）は、まだありません。版 2 で加えました。

購入や申し込みの確定ボタンは、拡張機能には押させず、人が押します。そのため、次のように扱います。

- 記録中に確定ボタンを押すと、クリックではなく `pause` として記録します。ページにその旨を表示します。
  記録中に押したクリックそのものは止めないため、実際に確定します。
- 実行時は、クリックの手順ごとに、押す直前に要素の文言を確かめます。確定ボタンであれば押さずに
  実行を終了します。JSON を直接編集して加えたクリックの手順にも有効です。

確定ボタンかどうかは、要素の表示文字列、`aria-label`、`title`、`value`、要素の中の画像の `alt` に、
確定を表す語（「注文を確定」「購入する」「Place your order」「Buy now」など）が含まれるかで判定します。
語の一覧は `extension/shared/purchase-guard.js` にあります。文言で判定するため、画像だけで説明のない
ボタンや、独自の文言のボタンは検出できない場合があります。確定ではないボタンを確定ボタンと判定し、
不要に止まる場合もあります。

文言で判定できないボタンや画面に備え、利用者はフローの管理画面で、サイト（オリジン）ごとに「必ず
止まる場所」を指定できます。指定はフロー定義には含めず、`chrome.storage.local` の `stopRules` に
フローとは別に保存します。そのサイトのすべてのフローに効き、フローの JSON を編集しても外せません。

- 止める要素：CSS セレクター。クリックする要素、またはその祖先の要素が一致した場合に止まります。
- 止める画面：URL のパス。`*` は `/` を含む任意の文字列に一致します。クエリ文字列（`?` 以降）と
  ページ内の位置（`#` 以降）は比べません。表示中のページが一致した場合、クリック・入力・選択を行わずに
  止まります。

記録中は、止める要素に一致するクリックと、止める画面でのクリックを `pause` として記録します。直前の
手順がすでに `pause` の場合は、重ねて記録しません。

## パラメータ（`params`）

実行のたびに変わる値（検索語、サイズ、対象月など）を定義します。実行するとき、サイドパネルに
パラメータごとの入力欄を表示し、入力した値を手順に当てはめます。入力した値は保存しません。

```json
"params": [
  { "name": "keyword", "label": "検索語", "type": "text" },
  { "name": "size", "label": "サイズ", "type": "select", "options": ["S", "M", "L"], "default": "M" },
  { "name": "target", "label": "対象月", "type": "month", "default": "@previous-month" }
]
```

| 項目 | 内容 |
|---|---|
| `name` | 名前。英字または `_` で始め、英数字と `_` だけを使います。同じ名前は使えません。 |
| `label` | 入力欄に表示する説明。 |
| `type` | 種類。`text`（文字列）、`number`（数値）、`select`（選択肢）、`month`（年月）のいずれかです。 |
| `options` | 選択肢の一覧。`type` が `select` の場合に必須です。 |
| `default` | 既定値。省略できます。年月では `@current-month`（今月）と `@previous-month`（前月）も使えます。実行した日から計算します。 |

入力欄を空にした場合は既定値を使います。既定値もない場合は実行できません。

### 手順での使い方

手順の次の値の中に `{{名前}}` と書くと、実行時に入力した値に置き換えます。

- `input` の `value`
- `select` の `values`
- `navigate` の `url`

年月のパラメータでは、次の書き方も使えます。対象月が 2026 年 8 月の場合の例です。

| 書き方 | 値 |
|---|---|
| `{{target}}` | `2026-08` |
| `{{target.year}}` | `2026` |
| `{{target.month}}` | `8` |
| `{{target.mm}}` | `08` |

定義していない名前を参照すると、形式の誤りとして保存できません。`navigate` の `url` に値を当てはめた
結果が、`origin` とは別のサイトになる場合は実行しません。

### 値を記録していない入力欄

`secret: true` の入力欄（パスワードなど）は、実行するときに入力欄を自動で追加します。パラメータとして
定義する必要はありません。入力した値は保存しません。

## 要素の指定（`target`）

| 項目 | 内容 |
|---|---|
| `selectors` | 要素を見つけるための CSS セレクター。優先する順に並びます。1 つ以上あります。 |
| `tag` | 要素のタグ名（小文字）。 |
| `label` | 人が読むための説明。`aria-label`、対応する `label` 要素の文字、表示文字列、`placeholder`、`title`、`name`、`id` の順に、最初に見つかったものです。どれもない場合はタグ名です。 |
| `text` | 要素の表示文字列（100 文字まで）。ボタンやリンクにあり、入力欄にはありません。ボタンとして表示される `input` 要素では `value`（画像の場合は `alt`）です。 |

`selectors` は、ページの構造が変わっても同じ要素を指しやすい順に並べます。

1. `id`（自動で生成されたとみられるものは除きます。例：`ember123`、`react-select-3-input`）
2. `data-testid`、`data-test`、`data-qa`、`name`、`aria-label`、`placeholder` の属性
3. 何番目の要素かをたどる指定（例：`#main > div:nth-of-type(2) > button`）

1 と 2 は、記録した時点でページ内のその要素だけを指すものだけを残します。3 は常に最後に 1 つ入ります。
