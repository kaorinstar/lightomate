保存したフロー

    実行する順（選んだ順）。別のサイトのフローは並行して、同じサイトのフローはこの順に 1 件ずつ実行します。

      該当するフローはありません。

      保存したフローはまだありません。サイドパネルの［記録開始］で作成できます。JSON のファイルがある場合は［JSON から追加］を押してください。

      左の一覧からフローを選ぶと、手順と実行時に入力する値を表示します。

      入力した値は保存しません。

      実行時に入力する値

      実行時に入力する値はありません。

      実行するたびに入力する値を定めます。手順の中では {{名前}} と書くと、入力した値に置き換わります。

      • 名前を変えると、手順の中の {{名前}} も合わせて変わります。
      • 既定値を決めておくと、入力を空にしたときにその値を使います。

      手順

      ブロックを並べ替えて、手順を変えます。［手順を保存］を押すまで保存しません。

      • 追加：左の一覧から、ページを開く・待つ・一時停止・PDF の保存・タブを閉じる、を足せます。
      • クリックや入力：記録するか、既存のブロックを右クリックして［複製］し、置きたい場所へ動かします。
      • キーボード：ブロックを選んで M キーで動かし始め、矢印キーで動かし、Enter キーで決めます。

      実行速度

      手順と手順の間に、最短と最長の間で毎回変わる時間だけ待ちます。

      • 1 秒以上、60 秒以下で入力します。
      • 片方だけ入力すると、両方に同じ値を入れます。
      • 両方を空欄にすると、既定の 1 秒です。
      秒 〜 秒

      定期実行

      設定した日時に、背景のタブで実行します。

      • 開始・完了・一時停止は、Windows の通知で知らせます。
      • Chrome を起動している間だけ実行します。

      このフローは定期実行できません

      日

      JSON を直接編集（上級者向け）

      形式は、リポジトリの docs/flow-format.md に記載しています。保存する前に形式を検証し、誤りがあれば保存しません。

      JSON からフローを追加

      フロー定義の JSON を貼り付けるか、ファイルを選んでください。

      • 一覧で複数のフローを選んで書き出したファイルも読み込めます。
      • 追加する前に、フローが操作するサイトを確認します。

      複数のフローを 1 つにまとめ、まとめて実行します。

      • 登録：［保存したフロー］の一覧でフローを選び、［まとめフローとして保存］を押します。
      • 実行の順：別のサイトのフローは、背景のタブで並行して実行します（同時に 3 件まで）。同じサイトのフローは、登録した順に 1 件ずつ実行します。
      • 確定ボタンの手前で止まった場合：サイドパネルで［確認済み・次へ］を押すまで、同じサイトの次のフローを始めません。
      • 実行の状態：サイドパネルに表示します。

      まとめフロー

        該当するまとめフローはありません。

        まとめフローはまだありません。［保存したフロー］でフローを選び、［まとめフローとして保存］を押すと作成できます。

        確定ボタンの文言で判定できないボタンや画面を、サイトごとに指定します。

        • 実行：指定したサイトのすべてのフローで、その手前で止まります。
        • 記録：記録中にクリックした場合は、一時停止として記録します。

        指定したサイト

        指定はまだありません。「サイトごとの指定」にサイトと止める要素を入力し、［このサイトの指定を保存］を押すと追加できます。

        サイトごとの指定

        https:// または http:// から始まる、サイトの先頭の部分（オリジン）です。例：https://www.amazon.co.jp

        CSS セレクター（ページの要素を指す書き方）を、1 行に 1 件書きます。例：#placeOrder

        URL のパス（サイトの先頭の部分より後ろ）を、1 行に 1 件書きます。* は任意の文字列です。例：/checkout/*

        フローを実行した結果を、新しい順に最大 200 件まで残します。

        • 実行するときに入力した値は記録しません。
        • 止まった理由、手順、ページの URL の中の入力した値は「＊＊＊」に置き換えます。
        • 履歴を削除しても、保存したファイルは削除しません。

        実行履歴

        実行履歴はまだありません。フローを実行すると、結果がここに記録されます。

        開始 フロー 結果 止まった手順と理由 保存したファイル コピーと削除

        サイトの許可

        オンにすると、記録と実行で、サイトごとに許可を求める確認を出しません。

        • 記録中に別のサイトへ移動した場合も、確認なしで記録を続けます。
        • オンにするときに Chrome が表示する確認には「すべてのサイト上にある自分のデータの読み取りと変更」と表示されます。Lightomate がページを操作するのは、記録中のタブと実行中のタブだけです。実行時は、手順を記録したサイトのページでだけ入力とクリックを行います。
        • オフにすると、個別に許可したサイトだけに戻ります。

        バックアップ

        保存したフロー、まとめフロー、必ず止まる場所を、1 つのファイルに書き出します。

        • Chrome の再インストールや PC の買い替えの前に書き出しておくと、復元で元に戻せます。
        • 復元は追加だけを行い、今あるデータは消しません。
        • 同じ内容のフローと、同じサイトの必ず止まる場所は追加しません。
