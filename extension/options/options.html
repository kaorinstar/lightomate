    実行時に入力する値

    実行の速度

    手順と手順の間に、最短と最長の間で毎回変わる時間だけ待ちます。片方だけ入力すると、両方に同じ値を入れます。両方を空欄にすると、既定の 1 秒です。

    秒 〜 秒

    手順

      JSON を直接編集（上級者向け）

      形式は、リポジトリの docs/flow-format.md に記載しています。保存する前に形式を検証し、誤りがあれば保存しません。

      JSON からフローを追加

      フロー定義の JSON を貼り付けるか、ファイルを選んでください。追加する前に、 フローが操作するサイトを確認します。

      確定ボタンの文言で判定できないボタンや画面を、サイトごとに指定します。指定したサイトのすべてのフローで、実行はその手前で止まります。記録中にクリックした場合は、一時停止として記録します。

      サイトごとの指定

      フローを実行した結果を、新しい順に最大 200 件まで残します。実行するときに入力した値は記録しません。止まった理由の中の入力した値は「＊＊＊」に置き換えます。履歴を削除しても、保存したファイルは削除しません。
