保存したフロー

左の一覧からフローを選ぶと、ここで JSON を編集できます。

フロー定義の JSON を直接編集できます。形式は、リポジトリの docs/flow-format.md に記載しています。保存する前に形式を検証し、誤りがあれば保存しません。

JSON からフローを追加

フロー定義の JSON を貼り付けるか、ファイルを選んでください。追加する前に、 フローが操作するサイトを確認します。

必ず止まる場所（サイトごと）

確定ボタンの文言で判定できないボタンや画面を、サイトごとに指定します。指定したサイトのすべてのフローで、実行はその手前で止まります。記録中にクリックした場合は、一時停止として記録します。
